▶ Cara dapetin Discord User ID — Mobile & Desktop
  1. Buka aplikasi Discord di HP lo
  2. Tap avatar lo di pojok kanan bawah → Settings (ikon ⚙️)
  3. Scroll ke bawah → Advanced (di bawah "App Settings")
  4. Aktifin toggle Developer Mode
  5. Balik ke chat → tap nama lo sendiri (di pesan/daftar member)
  6. Tap Copy User ID → paste di kolom atas
💡 User ID itu angka 17-18 digit (contoh: 845621095803221222) — bukan username lo (misal @xinde).
  1. Buka Discord di laptop/PC (app atau browser)
  2. Klik ikon Settings ⚙️ di pojok kiri bawah (deket avatar lo)
  3. Klik Advanced di menu kiri (di bawah "App Settings")
  4. Nyalain toggle Developer Mode
  5. Tutup settings → klik kanan nama lo (di chat atau daftar member)
  6. Klik Copy User ID → paste di kolom atas
