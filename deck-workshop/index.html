Modul 3 · Beginner

Intro AI Agent + kenalan 5 jenis Hermes.

KONSEP
Agent ≠ Chatbot
  • Chatbot nunggu input — hidup cuma saat lo buka chat.
  • Agent eksekusi tugas — jalan sendiri sesuai jadwal & aturan.
  • Output dikirim ke channel: WA, Telegram, email — bukan cuma layar.
PRAKTIK
Latihan live: pilih agent lo
  • Pilih 1 dari 5 jenis Hermes yang paling nyambung sama kerjaan lo.
  • Tulis satu tugas berulang yang mau lo serahkan.
  • Pilihan ini dipakai sepanjang modul build — jangan overthink.

Fundamental yang sama, diarahkan ke kebutuhan spesifik lo.

Modul 6 · Level-up

Loop engineering: agent makin akurat.

LOOP INTI
Evaluate → Refine → Repeat
  • Evaluate: jalankan agent, kumpulkan hasil & kesalahan.
  • Refine: perbaiki aturan atau konteks — bukan ulang dari nol.
  • Repeat: loop sampe output konsisten sesuai ekspektasi.
BATAS
Aturan main biar ga ngamuk
  • Kalau gagal 3x, eskalasi ke human.
  • Simpan versi prompt + hasilnya — bisa dibandingkan.
  • Catat kasus gagal jadi regression test.

Ini yang membedakan agent mainan vs agent produksi.

Tambal

Agent salah itu pasti. Yang penting: buang ke sampah, atau tambal & uji?

Modul 10 · Bonus

Algoritma by design: keputusan bercabang.

RANCANG
Pohon keputusan
  • Tiap cabang = satu kondisi nyata di bisnis lo.
  • Kondisi high-stakes → human yang ambil alih.
  • Loop terbatas: maks 3 percobaan, lalu fallback manual.
CONTOH
Agent follow-up cabang
  • Leads panas? → follow-up langsung
  • Leads ragu? → kirim social proof
  • Leads dingin > 7 hari? → arkipkan, jangan ganggu
  • Nomor invalid? → eskalasi ke human

Yang bikin agent terasa "pintar" bukan model — tapi desain.
