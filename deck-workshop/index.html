Modul 1 · Mindset

Identify. Adapt. Automate.

IDENTIFY · ADAPT · AUTOMATE
  • Identifikasi workflow kerja kamu — mana yang berulang dan bisa diimplementasikan ke AI.
  • Adaptasikan workflow itu jadi step-by-step yang nantinya digantikan AI Agent.
  • Automatiskan yang perlu, minta persetujuan untuk yang penting.
TRIAL · ERROR · EVALUATE
  • Berani mencoba walaupun awalnya berantakan — nggak masalah.
  • Kalau ada error, pakai reverse engineer buat identifikasi errornya di mana.
  • Evaluasi setiap workflow, test sampai 100% sesuai keinginan kamu.
EXPERIMENT
  • Experiment dengan batasan — supaya data-data kamu tetap aman.
  • Mulai dari scope kecil, jangan langsung semua.
  • Yang penting: jalan dulu, sempurna belakangan.

Mindset ini fondasi semua modul berikutnya — lo jadi arsitek, bukan tukang.

Modul 2 · Intro to AI Agents

Agent vs Chatbot.

🤖 AI Agent

  • Bersifat proaktif-otonom
  • Mampu merencanakan langkah sendiri
  • Menjalankan tool eksternal
  • Memantau hasil eksekusi
  • Mengulang eksekusi kalau terjadi error

💬 Chatbot

  • Bersifat pasif-reaktif
  • Hanya merespons prompt
  • Kerjanya dalam satu sesi teks saja
  • Nggak punya rencana sendiri
  • Nggak bisa jalan tanpa kamu ketik
Modul 2 · Lanjutan

AI Harness & AI Automation.

AI HARNESS "Tali pengaman" buat AI

Harness = lapisan yang ngatur cara AI berpikir & bertindak. Dia yang kasih aturan, tool, dan batasan — supaya agent nggak ngawur. Hermes Agent itu harness-nya.

AI AUTOMATION Dari "bisa" jadi "jalan sendiri"

Automation = waktu agent udah bisa mikir + punya tool, tugas itu dijalankan otomatis tanpa kamu ketik ulang. Trigger, jadwal, event — agent yang handle.

Harness tanpa automation = pintar tapi nunggu. Automation tanpa harness = jalan tapi ngawur. Butuh dua-duanya.

Hermes: framework autonomous agent open-source.

Dikembangkan oleh Nous Research. Sebuah orkestrator antar program lewat LLM — jadi bisa melakukan aksi nyata, bukan cuma membalas chat.

WHY 01

WHY 02

WHY 03

Komunitas tumbuh — sudah dilengkapi Skill Hub & Plugin Hub.

Modul 3 · Infrastruktur

Cloud/VPS vs Lokal.

☁️ Cloud / Virtual Private Server

Pros
  • Aktif 24/7 tanpa mati
  • Server stabil, nggak pernah tidur
  • Nggak perlu dibawa-bawa
  • Tugas yang udah di-set beneran dieksekusi
Cons
  • Sewa bulanan
  • Kalau salah setting keamanan bisa bocor
  • Datanya milik server, bukan pribadi

💻 Lokal / Mac Mini, Laptop

Pros
  • Biaya tambahan hampir nol
  • Data milik pribadi, mudah diawasi & dimatikan
  • Pas untuk belajar
Cons
  • Laptop ketutup / server mati = agent OFF
  • Kinerja tergantung spek laptop kamu

Lokal buat latihan & eksperimen. Cloud buat agent yang harus jalan 24/7.

Modul 5 · Give Your Agent Life

SOUL.md — kepribadian agent kamu.

Hermes punya profile yang disebut SOUL.md: jati diri, gaya, kepribadian, dan karakter sang agent.

KEPRIBADIAN

Mau agent punya kepribadian seperti siapa? Contoh: Engineering, CEO. Value apa yang mau kamu tanamkan.

GAYA

Cara berbicara: santai, formal, ala jaksel, to the point. Atur sesuai kamu — atau dia menyesuaikan sendiri.

LARANGAN

Jelaskan apa yang tidak boleh dilanggar oleh sang agent.

TEKNIS

Gimana agent menangani hal teknis. Contoh: fokus yang simpel dulu, baru yang ribet.

Agent tanpa SOUL.md = robot generik. Agent dengan SOUL.md = asisten yang punya karakter.

Modul 7 · Loop Engineering

Biar agent memperbaiki diri sendiri.

Loop Engineering merancang bagaimana agen berpikir, bertindak, mengevaluasi hasil, dan memperbaiki diri secara berulang sampai tujuan tercapai.

REASON-ACT-OBSERVE

Siklus dasar: agent menganalisis situasi (reason), memanggil tool eksternal (act), lalu baca data hasilnya (observe) buat nentuin langkah berikutnya.

TERMINATION CRITERIA

Aturan ketat kapan loop harus berhenti — karena tugas selesai, atau batas toleransi tercapai.

SELF-CORRECTION

Saat eksekusi gagal, log error dikembalikan ke model supaya sistem revisi parameternya sendiri — bukan langsung berhenti atau macet.

CIRCUIT BREAKERS

Pembatasan deterministik: max_steps, batas token, atau waktu tunggu — biar nggak terjebak infinite loop yang boros.
