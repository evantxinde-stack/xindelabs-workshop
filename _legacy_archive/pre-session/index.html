Fokus 1: Persiapan Aplikasi & Akses API

Daftar dan pasang 5 aplikasi utama berikut. Centang kotak di bagian bawah setiap kartu setelah selesai.

STEP 01 Channel Komunikasi

Telegram Desktop & @BotFather

Digunakan untuk mengobrol dan menerima laporan otomatis dari Hermes Messaging Gateway.

  1. Unduh Telegram Desktop (atau via Microsoft Store) lalu login.
  2. Cari akun resmi @BotFather mengacu pada Tutorial Team Telegram Assistant.
  3. Kirim perintah /newbot, tentukan nama tampil serta username berakhiran bot.
  4. Salin dan simpan Bot Token yang diberikan oleh BotFather.
STEP 02 Repositori & Versi

GitHub Account & Git Dasar

Tempat menyimpan konfigurasi agen, file instruksi AGENTS.md, dan repositori proyek.

  1. Daftar akun gratis di Halaman Sign Up GitHub sesuai Panduan Akun GitHub.
  2. Verifikasi email kamu dan pasang Git sesuai Dokumentasi Set Up Git.
STEP 03 Frontend & Webhook

Vercel (Di-link ke GitHub)

Platform cloud deployment instan untuk meng-online-kan antarmuka web atau dashboard agen.

  1. Buka Halaman Sign Up Vercel.
  2. Pilih Continue with GitHub dan berikan izin akses mengacu pada Dokumentasi Akun Vercel.
STEP 04 AI Coding Agent

Instalasi OpenCode CLI / Desktop

Asisten AI terminal (OpenCode Docs & GitHub OpenCode) untuk membantu modifikasi skrip tanpa koding manual.

curl -fsSL https://opencode.ai/install | bash

Alternatif NPM / Windows (lihat Download OpenCode):

npm install -g opencode-ai
STEP 05 • LLM ENGINE Atria-Dawn-Preview • 256K Context

Daftar & Buat API Key di Atria ASI (api.atria-asi.ai)

Berdasarkan Dokumentasi Resmi Atria API, model Atria-Dawn-Preview mendukung konteks 256.000 token (output hingga 65.536 token) melalui endpoint /v1/chat/completions, /v1/messages, dan /v1/responses. Model ini khusus menerima input teks (text-only).

  1. Buka Konsol Atria ASI dan login dengan akun Google.
  2. Masuk ke menu API Key, beri nama (misalnya hermes-agent), lalu klik buat kunci.
  3. Salin kunci atr_xxx saat itu juga (hanya tampil satu kali) dan uji dengan perintah berikut:
export ATRIA_API_KEY=atr_xxx curl -X POST https://api.atria-asi.ai/v1/chat/completions \ -H "Authorization: Bearer $ATRIA_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model": "Atria-Dawn-Preview", "messages": [{"role": "user", "content": "Halo!"}]}'

Fokus 3: Cara Install & Setup Hermes Agent

Ikuti panduan resmi dari Dokumentasi Instalasi Hermes Agent untuk memasang agen, menghubungkan model Atria Dawn Preview, dan mengaktifkan bot Telegram.

TAHAP 01 • INSTALASI Pilih Sesuai OS / Server

Pasang Hermes Agent di VPS atau Laptop

Jalankan perintah satu baris resmi di terminal Linux (Ubuntu/Debian), macOS, atau WSL2 mengacu pada Hermes Agent Installation:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Tips VPS 1 GB RAM: Tambahkan --skip-browser --skip-computer-use bila tidak memakai fitur browser. Lalu muat ulang shell:

source ~/.bashrc && hermes

Buka PowerShell di Windows 10/11 dan jalankan installer mengacu pada Windows Native Guide:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Unduh paket aplikasi grafis untuk Windows atau macOS (khusus prosesor Apple Silicon) di halaman Hermes Desktop, atau jalankan perintah berikut setelah instalasi CLI sesuai Dokumentasi Hermes Desktop:

hermes desktop

Saat merakit VPS di VPSMurah.co.id, pilih Hermes Agent pada menu dropdown 📦 Install Aplikasi. Hermes otomatis terpasang saat server selesai dibuat!

TAHAP 02 • MODEL AI Custom Endpoint

Hubungkan ke Model Atria-Dawn-Preview

Sesuai panduan Integrasi Hermes di Atria API Docs, jalankan:

hermes model

Pilih Custom endpoint dan masukkan konfigurasi ini:

  • Base URL: https://api.atria-asi.ai/v1
  • API Key: atr_xxx
  • Model: Atria-Dawn-Preview
  • Format: OpenAI
TAHAP 03 • GATEWAY 24/7 Telegram & Doctor

Aktifkan Bot Telegram & Lingering

Jalankan wizard gateway sesuai Tutorial Team Telegram Assistant:

hermes gateway setup

Untuk menjaga agen tetap jalan 24/7 saat keluar dari SSH VPS Linux serta mengecek kesehatan instalasi:

sudo loginctl enable-linger $USER hermes doctor

Fokus 4: Susun Prompt & Action Plan

Kenali file Markdown Hermes. Lalu ubah pekerjaan berulang menjadi alur otomatisasi dan struktur tim AI yang jelas.

ARSITEKTUR KONTEKS File Markdown Hermes

Setiap File Punya Tugas Berbeda

Bayangkan Hermes punya beberapa buku petunjuk. Pilih buku yang tepat agar instruksi tidak tercampur.

FileIsiDipakai untuk
SOUL.mdIdentitas, karakter, nada bicaraAturan yang ikut agen ke semua proyek
USER.mdProfil, kebiasaan, preferensi kamuPersonalisasi jawaban
MEMORY.mdFakta environment, proyek, pelajaranCatatan teknis jangka panjang
SKILL.mdProsedur langkah demi langkahPekerjaan berulang atau SOP
AGENTS.mdArsitektur dan aturan repositoriSatu proyek tertentu

Rule of thumb: lintas proyek → SOUL.md · fakta singkat → USER/MEMORY.md · SOP → SKILL.md · aturan repositori → AGENTS.md.

ACTION 01Petakan

List Pekerjaan Berulang

Tulis pekerjaan yang sering diulang dan paling menguras waktu. Contoh: riset konten, follow-up lead, laporan, atau balas komentar.

ACTION 02Otomatiskan

Petakan Alurnya

Urutkan: input apa yang masuk, siapa yang mengerjakan, alat apa yang dipakai, dan output apa yang harus jadi.

ACTION 03Bentuk Tim

Tentukan Struktur Agent

Pilih satu agent utama atau beberapa worker. Contoh: Researcher → Writer → Reviewer → Publisher.

ACTION 04Prompt Pertama

Tulis Brief Agent

Isi siapa agent ini, apa pekerjaannya, inputnya, outputnya, batasannya, dan kapan tugas dianggap selesai.
